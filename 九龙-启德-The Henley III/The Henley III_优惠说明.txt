====================================================================
               The Henley III (第3期) 价单优惠条件及印花税代缴规则
====================================================================

一、 付款计划与基础折扣率 (Cash Payment Plan & Base Discounts)
--------------------------------------------------------------------
1. 现金付款计划 - 90天成交：依照售价减 3.5% (即售价的 96.5%)。
2. 特别折扣优惠：
   - 凡选购实用面积为 420 平方呎或以下的住宅物业 (小户型)，可获额外 5.5% 售价折扣。
   - 实用面积大于 420 平方呎的住宅物业 (大户型) 不享有此额外折扣。
3. 综合最高折扣率：
   - 实用面积 <= 420 平方呎 (小户型)：3.5% + 5.5% = 9.0% 折扣
   - 实用面积 >  420 平方呎 (大户型)：3.5% 折扣

二、 代缴从价印花税优惠 (Ad Valorem Stamp Duty Benefit)
--------------------------------------------------------------------
买方可获卖方代缴/代折从价印花税，金额相等于按从价印花税第 2 标准税率 (Scale 2) 计算的实际税金。
该优惠仅适用于特定价单中的指定住宅物业 (仅限第3B座的特定单位)：

1. 【價單 1N 號】
   - 适用范围：第 3B 座 A 单位的 25, 27, 28, 29 楼

2. 【價單 2Q 號】
   - 适用范围：第 3B 座 B 单位的 16, 17, 33, 35 楼

3. 【價單 3O 號】
   - 适用范围：第 3B 座 B 单位的 22, 37, 38, 39 楼

4. 【價單 4L 號】
   - 适用范围：
     - 第 3B 座 A 单位的 17, 18, 19, 20, 21, 22, 23 楼
     - 第 3B 座 B 单位的 12, 15, 18, 20 楼

5. 【價單 4M 號】
   - 适用范围：
     - 第 3B 座 A 单位的 17, 18, 19, 20, 21, 22, 23 楼 (同 4L 號)
     - 第 3B 座 B 单位的 12, 15, 18, 20 楼 (同 4L 號)

6. 【價單 5L 號】
   - 适用范围：
     - 第 3B 座 A 单位的 9, 10, 12, 15, 16 楼
     - 第 3B 座 B 单位的 9, 10 楼

7. 【價單 6B 號】
   - 适用范围：
     - 第 3B 座 A 单位的 2, 3, 5, 6, 7, 8, 39 楼
     - 第 3B 座 B 单位的 2, 3, 5, 6, 7, 8 楼

三、 售价折算与取整规则 (Calculation & Rounding Rules)
--------------------------------------------------------------------
1. 合同售价 (临约签定价) = 官方售价 (原价) * (1 - 现金折扣率)
   - 注：折扣计算得出的金额，向下取整至百位数。
2. 代缴印花税额 = 以合同售价为基数，按照从价印花税第 2 标准税率 (Scale 2) 公式计算。
3. 最终最高折实售价 = 合同售价 - 代缴印花税额
   - 注：最终折实售价，向下取整至百位数。
4. 最惠总折扣率 = (官方售价 - 最终最高折实售价) / 官方售价

四、 典型单位精算示例 (Examples)
--------------------------------------------------------------------
示例 1：第 3B 座 15 楼 B 室 (大户型)
- 实用面积：540 平方呎 (大于 420 呎，现金折扣 3.5%)
- 官方原售价：$17,937,000 元 (对应价单 4M 號)
- 合同售价：$17,937,000 * 96.5% = $17,309,205 -> 向下取整至百位 = $17,309,200 元
- 印花税代缴：是 (在价单 4M 號的代缴范围内)
- 代缴印花税金额 (Scale 2)：$17,309,200 * 3.75% = $649,095 元
- 最终最低折实售价：$17,309,200 - $649,095 = $16,660,105 -> 向下取整至百位 = $16,660,100 元
- 最惠总折扣率：(17,937,000 - 16,660,100) / 17,937,000 = 7.119%
- 最终折实实用呎价：$16,660,100 / 540 = $30,852 / 呎

示例 2：第 3B 座 7 楼 B 室 (小户型)
- 实用面积：352 平方呎 (小于 420 呎，现金折扣 9.0%)
- 官方原售价：$9,313,000 元 (对应价单 6B 號)
- 合同售价：$9,313,000 * 91% = $8,474,830 -> 向下取整至百位 = $8,474,800 元
- 印花税代缴：是 (在价单 6B 號的代缴范围内)
- 代缴印花税金额 (Scale 2)：$8,474,800 * 3% = $254,244 元
- 最终最低折实售价：$8,474,800 - $254,244 = $8,220,556 -> 向下取整至百位 = $8,220,500 元
- 最惠总折扣率：(9,313,000 - 8,220,500) / 9,313,000 = 11.731%
- 最终折实实用呎价：$8,220,500 / 352 = $23,354 / 呎
